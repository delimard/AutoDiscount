# AutoDiscount

Module Thelia qui applique automatiquement une remise en pourcentage selon des paliers de montant panier configurables.

## Fonctionnalités

- Remise automatique dès qu’un palier de montant est atteint
- Gestion de plusieurs paliers de déclenchement
- Configuration depuis l’administration Thelia

## Compatibilité

- Thelia `2.5+`

## Installation


### Installation

1. Copier le module dans `local/modules/AutoDiscount`
2. Activer le module dans le back-office Thelia

## Configuration

1. Ouvrir le back-office Thelia
2. Aller dans **Modules > AutoDiscount**
3. Définir un ou plusieurs paliers de montant panier
4. Associer le pourcentage de remise pour chaque palier
5. Enregistrer la configuration

## Utilisation

Le module applique automatiquement la remise correspondant au palier atteint par le montant du panier.
